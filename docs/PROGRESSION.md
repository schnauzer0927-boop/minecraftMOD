# Apex Predator 1.5.0 — 召喚とApex Fang

Minecraft 1.20.1 / Forge 47.4.10 / Java 17向け。従来のAI、Phase 3回復、モデル・37アニメーション、音量0.85のボスBGMと戦闘中の通常MUSIC抑止を維持します。

## Apex Beacon

通常の3×3作業台で作成します。

```text
N E N
C S C
O E O
```

| 記号 | 素材 | 個数 |
| --- | --- | --- |
| N | Netherite Ingot / ネザライトインゴット | 2 |
| E | Eye of Ender / エンダーアイ | 2 |
| C | Echo Shard / 残響の欠片 | 2 |
| S | Nether Star / ネザースター | 1 |
| O | Crying Obsidian / 泣く黒曜石 | 2 |

地面の上面を右クリックすると、位置を固定して100tick（通常5秒）の儀式を始めます。橙色の円、黒煙、集まる橙粒子、機械音、最後の発光を経てApexを召喚します。儀式中に武器へ持ち替えて構いません。

召喚はサーバー側でのみ成立します。周囲64ブロックに生存中のApexまたは他の儀式があれば使用できません。読み込み済みの安定した地面とApexの幅1.25・高さ2.7ブロックの空間が必要で、平和難易度では使用できません。儀式の終端でも床・空間・近隣ボスを再確認します。

Survivalでは召喚成功時だけ1個消費し、Creativeでは消費しません。儀式中にBeaconを失った、ログアウト・次元移動した、床や空間が塞がれた場合は取り消します。利用できない理由を英語・日本語のメッセージで表示します。

召喚されたApexは通常の追跡・BossBarを使い、Survival/Adventureの召喚者との交戦では既存の専用BGMが始まります。Creativeでの召喚だけでプレイヤーへの敵対を強制せず、BGMは既存の実交戦条件を維持します。

## Apex Core

既存のApex撃破ドロップを維持します。Lootingによる増量関数を使わず、基本1個をドロップします。Fangのレシピには4個必要です。

## Apex Fang

```text
C N C
C S C
B N B
```

| 記号 | 素材 | 個数 |
| --- | --- | --- |
| C | Apex Core | 4 |
| N | Netherite Ingot / ネザライトインゴット | 2 |
| S | Netherite Sword / ネザライトの剣 | 1 |
| B | Blaze Rod / ブレイズロッド | 2 |

基本攻撃力16、攻撃速度1.6、耐久3000の剣です。通常の剣エンチャントと金床を使え、ネザライトインゴットで修理します。黒い複合装甲刃と細い橙色の発光溝を持つ3Dアイテムモデルで、一人称・三人称・インベントリ用の表示変換を設定しています。

通常の近接攻撃はバニラの攻撃クールダウン・盾・防具・耐久消耗を使用し、命中時に少量の橙色斬撃を出します。

| 操作 | 能力 | 基本仕様 |
| --- | --- | --- |
| 右クリック | Predator Dash | 地上を前方約7ブロック。進路上の敵対MOBへ基本12ダメージ、耐久4消費 |
| スニーク＋右クリック | Apex Slash | 前方約9ブロックへ短い斬撃波。複数の敵対MOBへ基本10ダメージ、耐久6消費 |

両技は10秒（200tick）のクールダウンを共有し、一度の発動で同じ対象を繰り返し傷つけません。ダメージは通常の防具・無敵時間・Forgeイベントを尊重します。特殊技は敵対MOBを対象とし、通常の剣攻撃は従来どおりです。

ダッシュは壁・未読み込み領域・足場の切れ目で止まり、空中・水中・乗り物で飛び続ける移動には使えません。斬撃波も壁で止まり、長距離射撃の代用にはしません。
