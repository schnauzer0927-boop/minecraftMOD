# Coaster Engineering 2.0.0 — VOLCANIC ABYSS

Minecraft 1.20.1 / Forge 47.4.10 / Java 17。1.1ワールドを変更せず、固定seed20261012の独立した2.0ワールドを制作しました。旧成果物と旧テスト記録は保管しています。

## 走行と体験

- 車両の3Dモデル、テクスチャ、座席と基本的な乗車操作を維持。
- 62制御点・約2,126ブロックの新しい閉周回コース。探索、古代都市、怪物遭遇、逃走、噴火、落下、屋外脱出、帰還の8区間。
- バンク付きS字、ヘリックス、エアタイム形状、大きな落差、ローンチ、怪物前の停車と崖上の短い停車を組み合わせた速度プロファイル。
- 区間ごとの加速度、制動、速度倍率をJSON設定。停止後は実際の距離の増加を伴って加速し、曲率に応じて速度を制限。
- 途中降車後は、停止中の完全な無人編成を60tick後に安全な駅へ帰還。乗員、緊急停止、未読込・障害物のある駅への帰還を拒否。旧1.1の挙動は維持。
- 3両の距離間隔、全移動区間の衝突・チャンク確認、終点で距離0・速度0へ停車する処理を継続。
- 垂直ループは回転フレームの独立診断まで。実車の反転ループは未実装で、配布コースには含みません。

## ワールドと演出

- 大空間のクリスタル湖と滝、崩れた橋と古代都市、骨のアーチと巨大生命体の巣、溶岩湖と火山心臓部、外壁からの屋外脱出を別々の素材・照明で構築。
- レール・車体・乗客の空間を確保してから装飾。壁面連続性、座席の光量、全軌道のクリアランスを生成完了前に検査。
- JSONの24イベントを走行距離と連携。照明、警報、音楽切替、怪物、咆哮、岩の落下風パーティクル、噴火、扉、停車と再発進を管理。
- 演出専用の非戦闘Entityを追加。頭部の追従、発光する目、出現・咆哮・威嚇アニメーション。編集可能なBlockbenchモデルを同梱。
- 演出の失敗を走行計算から分離。イベント履歴と停車状態をSavedDataへ保存し、再ロード時には安全に中断。
- 建設後のチャンク保持の期限終了時に発生する例外を修正し、実チケットの解除を確認するGameTestを追加。

## 音楽・カメラ

- 乗客側の距離減衰なしMUSICカテゴリで5区間の音楽を切り替え、フェードと怪物遭遇時の静寂を制御。
- 交換可能なOGGファイル、リソースパック雛形、Suno等の1曲を区間へ切り出す変換スクリプトを用意。収録曲は仮音源です。
- 速度に応じた走行・風音、控えめなFOV・振動、怪物への短い視線誘導。各カメラ効果は個別に無効化できます。
- 実際の乗車フレームをチェックポイントで撮影する任意の検証コマンドを追加。撮影は列車の走行を操作しません。

## 導入

新JARを`mods/`へ、新ZIP内の`Coaster World - Volcanic Abyss 2.0`を`saves/`へ配置します。同じMOD IDの旧JARと同時に読み込ませないでください。旧ワールドと旧成果物を上書きする操作は不要です。

実測、画像での確認範囲、未実装・未検証項目は[TEST_RESULTS.md](TEST_RESULTS.md)、操作は[CONTROLS.md](CONTROLS.md)、BGM交換は[BGM_GUIDE.md](BGM_GUIDE.md)を参照してください。
