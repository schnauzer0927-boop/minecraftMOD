## 新しく確認できた公式情報

`S3-OLC-20231211-01` はOLCの2023年12月11日付「東京ディズニーランド／東京ディズニーシー 2024年度 春のスケジュール」。通常の公開HTTPS GETで **HTTP 200**、459,093 bytes のPDFを取得した。SHA256は `69b5e5fa19a2ab1b287a024dd93223eb26f330bc2acff0f8c7b4eaa39be89831`。

取得URL: https://www.olc.co.jp/ja/news/news_tdr/20231211_01/main/0/link/20231211_01.pdf

`pdftotext`で本文を読み、3ページ目をPNGへ描画して `view_image` で実際に閲覧した。3ページ目は「セレブレーティング・スペース・マウンテン：ザ・ファイナルイグニッション！」を2024年4月9日〜7月31日開催とし、当時のスペース・マウンテンが7月31日のパーク閉園をもってクローズすると明記している。ここで確認できた図はイベントロゴであり、入口・キュー・乗り場の写真ではない。内装の材料、寸法、柱、ゲート、乗降位置の根拠には用いない。

Stage 1 / 2 の [sources.md](sources.md) ではこのPDFの取得がCONNECT403で失敗していた。これは過去の結果として保持する。**今回の実際のHTTP成功と本文・画像閲覧は、以前の設定draft保存とは別の証拠**である。
