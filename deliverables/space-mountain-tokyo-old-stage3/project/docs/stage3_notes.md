# Stage 3 — 入口・待機列・宇宙旅行の出発駅

制作日: **2026年10月14日 (日本時間)**。外観の全体シルエットがゲーム内で概ね良好というユーザーの確認を受け、今回は主構造を変更しない内装追加に限定した。

## 空間の流れ

1. 入口階段で既存広場Y0から新しい床Y4へ上がる。入口は西寄りX107、帰還は東寄りX115で分ける。
2. 白いフレームと落ち着いた青の航路案内を持つ導入ロビーへ。屋外から清潔な宇宙旅行施設へ切り替える。
3. 西側の曲がるギャラリーを経て、整然とした折返しへ進む。天井、ガラス仕切り、床の青い案内線で見え方を変える。
4. ガラス越しの星図と軌道を見せる区間で期待感を作る。武器・軍事設備・むき出しの密集機械は使用しない。
5. 最後に高い発車フレームと明るい左右ホームが開ける。左側が乗車、右側が降車候補。ガラス管制室、青い床矢印、天井照明を配置する。
6. 降車後は別の帰還通路から元の入口右側へ戻る。中央のレール予定空間を横切る必要はない。

実物のキュー・駅内装の写真は今回も確認できていない。白・灰・青、清潔なレトロフューチャー、待機列で期待感を高めるという依頼に基づく**推定・創作補完**。東京版の実際の間取りや装飾を確認したと主張しない。詳しくは `stage3_sources.md`。

## 乗り場と手動レール

駅の範囲はX88～132/Z122～143、ホーム床Y4、人物の足元Y5、天井Y20。左右の有効ホームはX90～105とX115～130。中央X106～114/Z120～143/Y5～15は車両の予約空間で、装飾を置かない。幅9、高さ11ブロックの予約で、実際のレール中心候補はY6。

発車方向は北(-Z)。発車フレームの横渡り部はY17以上にあり、予約空間から離す。乗降柵には開口を設ける。ホームの高さや車両と座席の高さは、ユーザーの手動敷設後に調整・乗車検証が必要。中央は建築の空洞であり、駅停止や車両を実装していない。

Stage2の`future_ride_core`は座標もそのまま保護。旧`guide_*`と` south_station_approach`は初期の創作案であり、今回の駅の具体化に合わせて新しいJSONに置き換えた。これはデータ上の設計更新で、ワールド内の既設レールを削除・変換する処理ではない。ユーザー追加の保護は`user_keepout.json`を継続利用する。

## 再編集

`stage3_config.json`の`station_floor_y`と`queue_floor_y`を同じ値にすると、床・入口階段・帰還階段・人物導線・レール高さを連動できる。検査済みは既定Y4と変更Y5。許容入力範囲Y2～6でも、変更後は生成検査が通ることを確認する。天井はホーム床から15ブロック以上を確保し、`station_ceiling_y`や`queue_ceiling_y`も調整する。

`queue_width_blocks`は3/5/7、通常のレール余白は`normal_rail_width_blocks`と上下の値で変更できる。大きくした保護領域が通路に重なると、生成を止める検査がある。乗り場部品だけの位置調整・貼付は、その部品の共通原点とクリアランスを再確認する。

旧Stage2の配置済みブロックをPythonから上書きせず、既存座標への配置を抑止する。新しい床や壁も人物導線・レール予約・ユーザー保護を尊重する。空気を貼り付けて古いワールドを消す方式ではない。
