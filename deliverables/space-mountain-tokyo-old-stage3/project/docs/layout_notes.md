# 共有原点・分割・空間

`output/preview/preview-top.png` は生成ブロック上面、`layout-reservations.png` は予約領域と仮中心線の平面図。両方北が上、東が右。

敷地検討枠は (0,0)～(219,219)、原点は北西。中心X110/Z94、主要屋根R63、下部最外径約140、上部最高Y78。南正面入口の仮庇はおおむねX88～132/Z156～175。広場と植栽はZ154～210周辺。

中央保護領域: X85～135 / Y5～31 / Z69～119。南側駅候補: X102～118 / Y5～15 / Z121～160。いずれも両端含む、設計予約の創作。仮中心線の周りに1ブロック間隔で予約直方体を足し、幅・上下寸法はconfig.jsonを使用する。ガイドは曲線設計ではなく線分の仮案なので、本物のレール敷設前に曲率やバンクをMOD内で確認する。

X110/Z94を境界とする四分割の外観は同じclipboard origin0。西はX<110、東はX>=110、北はZ<94、南はZ>=94で、境界重複なし。4個の結合が外観全体ファイルとブロック単位で一致する。部品を別場所に貼ることで成立する構成ではない。

通常版部品は任意の共通ワールド原点 P に `//paste -a` し、実ブロック位置は P+プロジェクト座標。`prototype_half_scale.schem`だけは半分サイズの別試作で、通常版の位置へ足さない。guide_optionalのマゼンタガラスも任意オーバーレイで、全体版の構成ブロックではない。

内部空間の予約は生成データ上で塞がれないことを検査した。車両サイズ、動的サブレベル、ループ時の乗客頭上余白などの実MODクリアランスは未検証。ブロックを後から貼る場合にWorldEditがこのJSONを自動的に適用することもない。
