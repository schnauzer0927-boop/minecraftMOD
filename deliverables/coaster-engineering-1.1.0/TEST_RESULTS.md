## 建築・照明

元の完成ワールドを再生成せず、コピーに品質更新を適用しました。**屋内接合部など879のAIRセルを周囲の岩材へ補修し、2,678セルに照明・発光装飾を反映**しました。窓・入口・意図した屋外区間、車両と直立乗客の空間は保護します。既存の占有・編集セル28個はそのまま残しています。

品質処理中は乗車・発車をブロックし、更新前後に0.25ブロック間隔で車体と直立乗客の空間を検査します。照明伝播を待ち、座席の目の高さを2ブロック間隔で検査してから品質マーカーと速度設定を確定します。最初の照明案で暗い位置を検出したため、登降・バンクカーブ・駅の光源位置と間隔を修正しました。

最終版は **1,212座席光量プローブすべてが基準を満たしました**。駅は9以上、その他の区間は6以上を要求し、最終版ではブロック光だけでも最小6、平均10.17でした。昼のSKYとの合成最小6、平均11.40です。

実走行中にも全3両・2席をTickごとに確認しました。**15,678サンプル**（2,613 Tick×6席）のブロック光は最小6、平均9.997。ブロック光と生のSKYの合成平均10.724、暗い判定0〜3の割合0でした。SKYは時刻による減算前の値で、夜の照度ではありません。暗闇と明るい装飾のコントラストや、目立つ建築の見え方をこの数字だけで保証しません。

保存データの読み取り監査は0.5ブロック間隔、2,424軌道位置・4,848座席視点で行いました。

壁面・天井の連続性は32ブロックのレイで診断します。洞窟奥と意図した屋外区間を除く接合部の開口候補長は、左14.5→5.0、右29.0→2.5、天井17.5→0.5ブロックへ減少しました。**残った開口候補がすべて不自然な穴かどうかは未判定**です。斜めの室内接合・見通しのための開口も含むため、全てを閉塞しません。元の開放された屋外区間も維持しています。

実クライアントの乗車画面で、研究施設・探索トンネルの岩模様・天井・レール・連続誘導灯、高速走行中の描画、帰還と駅を確認しました。全ブロックの外観や、すべての主要オブジェクトが常に最適に見えることは未検証です。

## BGM・効果音・カメラ

- オリジナルBGM3曲は24秒・32 kHz・ステレオVorbis。RMSは−17.98／−18.01／−17.98 dBFS、最大デコードpeakは0.385未満。外部のサンプルや録音は使っていません。
- BGMの初期設定を0.35→0.8へ変更。既存の個人設定は上書きしません。音源自体も旧版より約6.6 dB上げ、ループ終端の音量の谷を改善しました。
- BGMはMUSICカテゴリ、プレイヤー相対、距離減衰なし。Minecraftの音楽・主音量を尊重し、40 Tickのフェードと区間クロスフェードを適用します。
- 速度連動の風切り・車輪ループを追加。各4秒のバッファ型ループです。BGM3曲だけがストリーミングです。効果音4個を合わせて**9音源、622,615バイト**。形式・RMS・peak・ループ境界・チェックサムを検査しました。
- 実クライアントで音源9/9、停車乗車中のmusic=1/motion=0、走行中の全3ゾーンでmusic=1/motion=2、降車後の両方0を確認。Coaster Engineeringの音源読込・再生エラーは発生していません。
- 追加カメラ振動は初期値0.18度、上限0.25度、FOV増加は初期値2%、上限3%。設定0で無効化できます。60 km/h超で滑らかに増加し、停止・降車で解除します。
- 純Javaカメラテスト6件成功。一人称・三人称を実走行中に切り替え、クラッシュせず継続しました。

クライアントの音声出力はOpenALの **No Output（仮想出力）**です。人間の耳でBGMの明瞭さ、ループの自然さ、効果音との聞こえ方を確認したとは報告しません。ループ境界の数値検査と稼働音源の診断も、可聴品質や走行中の一瞬の途切れの聴取確認とは別です。人間による音の聴取・酔いやすさ・Windows実機の性能は未検証です。

## 証拠と再実行

配布の `CoasterEngineering-Validation.zip` に、最終ビルドログ、JUnit XML、正式サーバーの更新・再起動ログと結果JSON、保存データ監査、音源検査、公式クライアントのログ・画面を収録します。チェックサムは同じ配布物の `SHA256SUMS` で確認してください。

```bash
./gradlew build runGameTestServer
python3 scripts/verify-preserved-design.py
python3 scripts/generate-audio.py --verify-only
python3 scripts/inspect-world.py --world "保存して終了したワールド" --require-ready --require-quality
python3 scripts/audit-world-quality.py --world "保存して終了したワールド" --output build/world-audit.json
```

通常のプレイ済みワールドはPlayer情報などを保持するため、初回配布用の `--require-ready` 条件を満たさない場合があります。再入場確認では実際の保存内容と品質マーカーを検査し、配布時に個人データを除去します。

今回の配布は既存ワールドを更新したものです。1.1.0でゼロから火山全体を再生成する経路、実同時複数人マルチプレイ、Apex Predatorとの併用は未検証です。既存のループ反転・複数編成・動的怪物AI・実流体・色付き動的照明は未実装のままです。元プロジェクトの追跡ファイルは変更していません。
