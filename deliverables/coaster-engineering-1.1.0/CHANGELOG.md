# Coaster Engineering 1.1.0 — 品質改善

Minecraft 1.20.1 / Forge 47.4.10 / Java 17。

## 維持した部分

- 車両モデル・描画コード・外観素材は1.0.0と完全に同じです。`scripts/verify-preserved-design.py`でSHA-256を検査できます。
- 45制御点の座標・バンク、周回レイアウト、火山の外観、洞窟・駅のテーマを維持します。
- 元の完成ワールドをバックアップし、そのコピーの建築・照明・速度設定を更新します。コースと3両のUUID、駅、自動発車、乗車方法を維持します。

## 修正

- 屋内トンネルと洞窟の接合部を周囲の岩素材に合わせて補修します。意図した屋外区間・入口・窓は維持します。
- 駅の低い位置、洞窟、水辺、溶岩、見せ場の怪物、高速区間に照明を追加します。Minecraft標準光源と色付きの装飾を組み合わせ、実際の光の色は標準のままです。
- BGM3曲の音量を約−18 dBFS RMSへ調整し、初期設定を0.35から0.8へ変更します。プレイヤー相対音源・距離減衰なし・Minecraft音楽/主音量に従う再生を維持します。
- ループの終端にあった音量の谷を改善し、乗車・区間切り替えをクロスフェード、降車後は約2秒でフェードアウトします。
- 探索、異変、高速、見せ場減速、クライマックス、帰還の速度目標を設けます。連続距離に沿って補間し、先読み制動で駅へ減速します。旧コースやデモの走行処理は保持します。
- 速度連動の風切り音・車輪音と、控えめなカメラ振動・FOV変化を追加します。設定からそれぞれ無効化できます。

## 更新時の注意

既存の`coasterengineering-client.toml`に保存した音量は上書きしません。以前の初期値0.35を使っている場合は、`attractionMusicVolume=0.8`を推奨します。最初にMinecraftの音楽・主音量を確認してください。

配布JARは1.1.0へ置き換え、1.0.0と同時に`mods`へ入れないでください。新しいワールドZIPは別のフォルダに展開し、既存ワールドを上書きしないでください。既存のプレイ済みワールドへ修正を適用する操作はREADMEを参照してください。

実施済みの試験、実測値、未検証項目は`TEST_RESULTS.md`に記載します。仮想音声出力による確認は、人間がBGMを聴いた確認とは区別します。

## 今回の保存ワールドでの結果

879セルの岩補修と2,678セルの照明・装飾を適用しました。45制御点の座標・バンクと車両外観を維持しています。正式サーバーで1周2,613 Tick（20 TPS換算130.65秒）、最高120 km/h、駅停止を確認し、保存・再起動後も同じ結果でした。更新前は3,569 Tick（178.45秒）です。実クライアントでも全周・降車・保存・再入場後の再乗車と全周を確認しました。
