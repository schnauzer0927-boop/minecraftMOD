# 検証結果 — Thunder Mine 1.1.0

## 実ゲームの結果

- 添付3JAR未改変。公式Minecraft1.21.1 / NeoForge21.1.228 / Java21で起動。旧2.0火山ワールド・JARのチェックサム一致を監査。
- 元の配布ZIPを実シングルプレイで開き、1.0.0の実乗客で189.275秒の完走・停車を確認。
- 同じ保存データの表示名だけを変更し、1.0.0の駅ボタン・運転制御が無反応になる欠陥を再現。車両は約22.18ブロックずれた。

- 1.1.0を同じワールドへ導入し、実乗客で1035.5979ブロックを171.425秒で完走。最高ネイティブ速度16.4650ブロック/秒（59.27km/h相当）。独立した実位置計測の瞬間最高17.1296ブロック/秒も別に記録。
- 1.1.0のガイド最大誤差0.32054ブロック、駅停止位置誤差0.06036、3.025秒以上停止。姿勢・レールガイド・読み込み済み先行チャンクを走行中確認。車両位置を直接書き換えて走行させていない。
- 1.1.0の演出7件・実行12回・エラー0。ブロック破壊なし。
- BGMの探索→坑道→疾走→帰還への切り替えと実SoundManager再生を確認。MUSICカテゴリ・音量0.65・NONE減衰・ループ。各曲のクロスフェードとShift降車後のfade_completeを確認。
- 1.1.0専用サーバーで、同じUUID・指紋・PASSED復元、速度0、クリアランス189592セルで違反0。10.17秒間の位置差約4.96e-8ブロック。通常保存・終了コード0。配布元はPlayerタグのないその保存ワールド。
