# Thunder Mine Expedition — オリジナル景観生成

この生成コードは添付MODのレール・車両・物理を変更しません。完成した本番nativeコースへ、Minecraft標準のブロックを使う独立した景観を追加します。実行前に、小規模試験だけでなく本番コースの裸の状態での実走行を確認してください。

## エリアと見せ場

- **採掘基地**：東側の木造乗降駅、銅の屋根の鉱石選別所、旧採掘会社の門、待機列、巻き上げ櫓、木箱と鉱石。駅の直線は元レールを保持し、乗車ボタンと1周発車・緊急停止ボタンを設けます。
- **荒野の外周**：赤茶色の不規則な岩山、自然な侵食柱、上昇区間の足場・展望台、放棄された圧縮機小屋。ダイナマイト風の赤い荷物は羊毛の装飾であり、TNTを使用しません。
- **坑道**：実際のnative曲線・姿勢に沿う粗い岩の内壁、木と鉄の支保工、鉱石、ランタン。大きな最初の下りを採掘山から坑道へつなげます。
- **巨大地下採掘場**：幅約150、長さ約220、高さ約140ブロックの不規則な岩殻。水を閉じ込めた沈殿池、複数の高さの足場、長い吊り歩道、巻き上げ櫓、発光鉱脈、鍾乳石を配置します。一本道のトンネルとは異なる大空間です。
- **峡谷**：高架と木の橋脚、自然の岩柱、摩耗した石のアーチ、古い信号小屋。急降下と屋外の開放感を見せた後、帰還坑道を通って駅へ戻ります。

固有の名称、施設ロゴ、既存テーマパークのレイアウトや素材をコピーしていません。景観は決定的な数式、独自の建築寸法、Minecraft標準ブロックだけで生成します。

## 安全と保存

`NativeClearance` は添付MODが返す実際のBezierレールの走行フレームを使用します。レール周辺は横半径4.6ブロック、上7・下5ブロックに加えて、ブロック寸法とサンプル間隔の余裕を含めて保護します。保護体積には通常の景観ブロックを置きません。

通常の保護に加えて、`simulatedcoasters`、Create等の標準外の名前空間のブロックと既存のブロックEntityを上書きしません。駅だけは、実車体から十分に離した側面平台と低い退避床を限定的に許可します。駅の例外は、実際の乗車・降車・発車で別途確認する必要があります。

配置はサーバースレッドで実行し、1tick最大6,000配置、45,000候補検査、20msのいずれかへ達すると次tickへ譲ります。大量のワールド変更を並列スレッドから行いません。進行位置・生成数・コースfingerprintを独立したSavedDataへ保存します。中断した場合は同じコースで`start`を再実行して再開できます。勝手な自動再生成は行いません。

地形の高さが急に変わる場所では、隣の地表まで岩の側面を埋め、露出する中空の隙間を防ぎます。開始ログに地形の連続性と候補ブロック数、ステージ完了ログに実配置数を記録します。`clearanceReport`は生成後の実ワールドを読み取り、保護領域のMinecraft固体ブロックを数えます。数値検査の成功だけでは、景色・乗車・FPSの検証完了になりません。

生成後の実ワールド検査で、重力を持つ赤い砂が保護領域へ落ちる不具合が見つかったため、表土を落下しない赤い砂岩へ変更しました。旧生成結果への`stabilizeTopsoil`は、同じ決定的な表土地位置に残る赤い砂だけを安定化します。既に落下した保護領域内のブロックは別に安全除去し、修復後と再読み込み後にclearance検査・実走行を繰り返してください。コース形状・車両・物理には触れません。

## 操作者向けAPI

- `MineSceneryGenerator.start(ServerLevel)`：生成開始・再開。root側の管理コマンドから明示的に呼び出します。
- `tick(ServerLevel)`：サーバーのレベルtickへ接続します。
- `status(ServerLevel)` / `isRunning(ServerLevel)`：進捗表示。
- `clearanceReport(ServerLevel)`：実ワールドの車両通過空間を読み取り検査。
- `detach(ServerLevel)`：レベルunloadでメモリ参照を解放。
- `stabilizeTopsoil(ServerLevel)`：旧生成結果の元の表土地位置に残る赤い砂を、最大10ms・3,000候補/tickで不動の赤い砂岩へ置換。中断しても再実行できる冪等な修復です。

ボタンは標準のButtonタグを持つブロックです。補助MODの操作処理をroot側で接続し、見た目だけのボタンで終わらないようにします。

## 景観確認

`data/scenery-viewpoints.json`に、駅と主要エリアの画面確認候補を記載しています。コースノードに対応する候補は設計上の視点であり、実際の乗車画面を撮影した証拠ではありません。実際のnative車両に乗って各地点を通過する画面と、再ロード後の同じ景観を確認してください。音を聞けない環境やFPS条件が異なる場合は、その項目を未検証として記録します。
