# Coaster Engineering download files

These are the existing completed files, copied byte-for-byte without rebuilding.
Minecraft Java Edition 1.20.1 / Forge 47.4.10 / Java 17.

Download each binary file using GitHub's Download raw file button.
Put coasterengineering-1.0.0.jar in your Minecraft mods folder.
Extract CoasterWorld-VolcanicAbyss.zip into saves, so Coaster World - Volcanic Abyss/level.dat exists.
Open the world, right-click a stopped coaster at the station and wait 7 seconds for departure.
The included SHA256SUMS verifies both existing binaries.
