# Stage 1/2 設計ノート

本試作の基準は閲覧済み写真 `S-GH-TDL-01`。写真観察、東京版への同定推定、見えない部分の補完は `sources.md` で分けている。形状を一つの汎用SFドームに置き換えず、平坦な頂部・放射リブ・太い水平帯・V字状柱を組み合わせた。

- Stage 1: 出典・取得結果・動画URL・確信度を保存。公式本文と動画未確認が残る。
- Stage 2: 切頂円錐外観、縮小試作、四分割外観、編集用層、プレビューを保存。
- Stage 3以降: 本格入口、キューライン、駅、内装、機械室、暗所照明、実コースに関する資料確認は未実装。

外観はx/z対称の放射造形。背面を観察できていないため全周を同一リズムに補完している。24本の屋根リブ、12本の頂部小突起、中央突起の高さは実測ではない。写真の白/クリームをコンクリートとクォーツで、溝を面の高さによる陰影で表現する。三角や曲面はMinecraftの階段状解像度になる。

入口前の庇、青いサイン状面、広場の矩形植栽、ライトは次工程の配置検討であり、2024年旧施設の実意匠だと主張しない。サインに実ロゴ画像は使用しない。内部を埋める柱やレールは配置せず、後で手動レールを配置するために基礎より上を空ける。

生成コードは材料・外観・入口・保護・仮ガイド・NBT出力・画像を独立させた。後の内装モジュールも `Model.set/box/line` を経由すれば追加の保護領域を尊重できる。再生成時のガイドや保護JSONは生のワールド編集命令ではない。

ソース変更に伴うgeometry reportの古さは、公開版の各ファイルSHA256とWorldEdit Reader報告で照合する。ブロック形状を変更したらまず生成とテストを行い、任意の正式Reader検査を再実行する。Windowsやゲーム内で試していない結果をLinuxの形式検査に混ぜない。
